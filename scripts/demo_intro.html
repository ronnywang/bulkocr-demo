手寫紙本表單批次整理

已知格式的手寫掃描表單，批次轉成結構化資料表（xlsx），再由人工逐欄校正。這裡用「醫療記錄單」的合成模擬資料展示，共 __N__ 份。

流程

1. 整頁 OCRPaddleOCR 辨識文字、座標和信心值
OCR
2. 對齊每頁都有、而且只出現一次的印刷字就是錨點，用來把每頁對到參考頁（誤差 < 2px）。所有頁面取中位數，就得到乾淨的空白表單
CPU
3. 模板 JSONAI 起草欄位位置、類型和驗證規則，再由人工在編輯器確認
純前端
4. 抽取勾選框：減去空白表單後算墨水比例。文字：裁切欄位後做 OCR，再正規化、驗證並標上旗標
CPU OCR
5. 逐欄校正一次看所有份數的同一個欄位，有旗標的排前面
純前端
6. 匯出 xlsx需要確認的儲存格標黃色，人工修正過的標藍色
CPU

試用

原始掃描檔加上 OCR 框。綠、橘、紅代表信心高低，點框可以看辨識出來的文字。
空白表單上疊著欄位框，底下半透明的是一份填寫過的範例。可以拖拉框、調整大小，逐欄標記已確認後匯出 JSON。
左側選欄位（例如「姓名」），右側列出每一份的裁切圖和辨識值。Enter 確認並跳下一筆；勾選欄位可以直接點框，或按數字鍵切換；點頁碼可以看整頁。

30 份模擬資料的結果

方法欄位正確率
整頁 OCR + 文字規則（不用模板）約 40–50%
模板 + 對齊 + 欄位裁切 OCR + 正規化68.6%
  • 勾選框：檢傷 100%、性別 97%、過敏 97%、診斷 87%。
  • 手寫數字和人名最難，大約 37–57%，所以需要人工校正。
  • 旗標是重點：95% 的錯誤值都會被旗標或低信心值抓出來，沒有旗標的值有 96% 是對的。校正時可以優先看有旗標的項目，沒有旗標的一鍵確認。

設計重點

  • 只有 OCR 需要 GPU：對齊、勾選判斷、驗證和匯出都在 CPU 上跑；模板編輯和校正是純前端，不需要伺服器。
  • 先對齊再裁切：用模板的固定位置抓欄位，比在整頁文字裡猜哪段是哪個欄位穩定得多。
  • 兩版 OCR 互相比對：每個欄位都送「去掉印刷字」和「原圖」兩版，結果不一致就標旗。

所有資料都是合成的模擬資料，不含真實個資。這個展示頁不會連線到任何 OCR 服務，所有資料都已經內嵌在檔案裡；你做的校正只會存在你自己的瀏覽器中。
